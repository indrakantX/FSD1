# Student Management System (React JS)

Practical No. 03 - Frontend Technologies

## Run
    npm install
    npm run dev
Open the URL shown (usually http://localhost:5173)

## Concepts demonstrated
- Components: App, StudentForm, StudentList, StudentRow
- Props: data (students, editingStudent) and callbacks (onAdd, onEdit, onDelete...) passed to children
- State: useState for students, editingStudent, search, form fields
- Effects: useEffect saves to localStorage and fills the form when editing
- Event handling: onChange, onSubmit, onClick
- Forms: controlled inputs with validation
- CRUD: Create (add), Read (list + search), Update (edit), Delete (with confirm)
